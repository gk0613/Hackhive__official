HACKHIVE OFFICIAL WEBSITE
=========================

Files:
- index.html       Main website content
- style.css        Design and responsive layout
- script.js        Mobile navigation and current year
- robots.txt       Search crawler instructions
- assets/favicon.svg  Browser tab icon

HOW TO PREVIEW:
1. Extract this ZIP.
2. Open index.html in Chrome, or open the folder in VS Code.
3. For local development, use the VS Code Live Server extension.

HOW TO PUBLISH ON NETLIFY:
1. Go to https://app.netlify.com/
2. Sign in to your Netlify account.
3. Choose Add new site / Deploy manually (wording may vary).
4. Drag the extracted website folder (the folder containing index.html) into the deploy area.
5. Netlify will provide a public URL.
6. Keep that URL; it will be needed for Google Search Console.

GOOGLE SEARCH:
1. Open https://search.google.com/search-console/
2. Add the deployed website as a URL-prefix property using its exact https:// Netlify URL.
3. Complete the verification method Google offers. For Netlify, an HTML file or DNS method may be available depending on the property type.
4. After verification, use URL Inspection for the homepage and request indexing.
5. Indexing and ranking are not guaranteed and can take days or weeks.
